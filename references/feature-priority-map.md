# Feature Priority Map

- **P0:** runtime, permissions, media import, Timeline state, preview, export, clip editing, capture, asset-package service.
- **P1:** complete editor shell, filters, captions, stickers, transitions, music, voiceover, beauty, AR, makeup, PIP, templates.
- **P2:** compound captions, masks, backgrounds, watermarks, animations, themes, local asset center, media tools, albums, covers, still-image export, custom video effects.
- **P3:** specialized capture patterns, sequence nesting, Live Photo host workflow, equalizer, lyrics, custom audio/transition rendering, advanced composition.

Select the minimum dependency-closed feature set. Do not add optional P2/P3 features merely because a broad blueprint exists.
