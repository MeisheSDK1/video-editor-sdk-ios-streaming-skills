# API Priority Map

- **P0:** required for SDK initialization, Timeline construction, media insertion, preview, capture, compile, and cleanup.
- **P1:** common product editing and AR/material workflows.
- **P2:** advanced but reusable media, template, custom-video, and composition APIs.
- **P3:** rare or specialized members retained for exact lookup and contract mapping.

Priority controls retrieval and implementation effort, not public API deletion. Never emit a P2/P3 member without a verified public signature and compatible code-unit state.
