# Feature List

Feature truth is the combination of module registry, resources, guards, and completion criteria. Major groups are:

- Core lifecycle and licensing
- Media import and Photos identifiers
- Timeline editing and project restoration
- Preview, playback, seek, and compile
- Capture preview, controls, effects, and recording
- Captions, compound captions, stickers, transitions, filters, themes
- Music, voiceover, waveform, and audio effects
- Asset package installation and application
- Human detection, AR Scene, beauty, shaping, makeup, segmentation
- Template workflows
- Media information, frame retrieval, thumbnail/icon/waveform generation, conversion
- PIP, quick splicing, covers, still-image export, advanced composition
- Custom video/audio effects and transitions

Read `sdk-module-registry.json` for dependency-closed implementation state.
